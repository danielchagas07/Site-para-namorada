Sobre o projeto

Este projeto foi desenvolvido de forma individual para a disciplina de **Engenharia de Software**, com o objetivo de aplicar na prática conceitos de desenvolvimento web, organização de código e versionamento com Git/GitHub.

O site é uma homenagem pessoal: uma página interativa pensada para ser aberta direto pelo link, sem precisar instalar nada.

Funcionalidades

- [x] Página responsiva (celular e computador)
- [x] Design romântico com paleta de cores suave
- [x] Elementos interativos com JavaScript
- [x] Acesso direto por link, sem instalação
- [ ] Ideias futuras: galeria de fotos, contador de tempo juntos, música de fundo

Tecnologias

| Tecnologia | Uso |
|------------|-----|
| HTML5 | Estrutura da página |
| CSS3 | Estilização, cores e animações |

Como acessar

Basta clicar no link: **[COLE-O-LINK-DO-SITE-AQUI](COLE-O-LINK-DO-SITE-AQUI)**

Como rodar localmente

1. Clone o repositório:
   `git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git`
2. Entre na pasta:
   `cd NOME-DO-REPOSITORIO`
3. Abra o arquivo `index.html` no navegador.
